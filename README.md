# Projectshare Import Test

A public test repository for verifying GitHub account connections, repository imports, and automatic README rendering in Projectshare.

## What to test

1. Connect the repository owner's GitHub account in Projectshare Settings.
2. Open Workspace → Import Project and select `project-share-test`.
3. Configure the project description, category, and technologies, then publish.
4. Open the published project and confirm this README appears.
5. Edit this README on GitHub and check that Projectshare refreshes it after its README cache expires.
